ANGIE YOLANDA BEAUTY PARLOUR
Adobe Dreamweaver Edition

1. Extract this ZIP.
2. In Dreamweaver choose Site > New Site.
3. Set the Local Site Folder to this extracted "Angie-Yolanda-Dreamweaver-Website" folder.
4. Open index.html.
5. To see/edit HTML code, choose View > Code, or click Code in the Code/Split/Design toolbar.
6. Edit colors and layout in css/style.css.
7. Edit menus in header.html and the page files.
8. Replace images inside images/ with your own images, keeping filenames or updating the HTML src paths.
9. The contact form uses mailto:your-email@example.com. Replace that address in contact.html.

Pages:
index.html
shop.html
services.html
gallery.html
about.html
contact.html

This version uses plain HTML5, CSS3 and vanilla JavaScript only. No Bootstrap, React, PHP or external libraries are required.
The .dwt file is included as a Dreamweaver template reference. The supplied pages are already standalone so they can be edited directly even if Dreamweaver Templates are not enabled.
